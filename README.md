# UP Fruit Company PWA (GitHub Pages)

1. Upload/replace all files and the `icons` folder in the root of the `UPFRUIT` repository.
2. GitHub Pages must publish from `main` branch, `/ (root)`.
3. Open `https://upfruitcompany1786-lab.github.io/UPFRUIT/` in Android Chrome.
4. If the old install error remains: Chrome > Settings > Site settings > All sites > `upfruitcompany1786-lab.github.io` > Clear & reset; then reopen the site and wait for it to finish loading.
5. Use Chrome menu > Install app (or Add to Home screen).

The Apps Script URL is configured in `config.js`. Change it only if the deployment URL changes.
